# Lab2 — Система управления турниром (фрагмент): Player / Match / Result

Проект — учебная лабораторная работа №2 по ООП на C++ (ручное управление памятью).
Реализован минимальный фрагмент предметной области турнира по настольным играм (шахматы/шашки):
- игроки (Player),
- матч между двумя игроками (Match),
- результат матча как часть матча (Result).

В коде демонстрируются:
- **композиция** (Match содержит Result и управляет его временем жизни),
- **агрегация** (Match ссылается на Player через указатели, не владея игроками),
- проверка одного правила предметной области,
- работа со стековыми и динамическими объектами (`new/delete`),
- работа со ссылками и указателями,
- динамические массивы объектов и массивы динамических объектов.

---

## Структура проекта

- `include/`
  - `player.hpp` — объявление класса Player
  - `match.hpp` — объявление класса Match
  - `result.hpp` — объявление класса Result
- `src/`
  - `player.cpp` — реализация методов Player
  - `match.cpp` — реализация методов Match
  - `result.cpp` — реализация методов Result
  - `main.cpp` — демонстрационная программа
- `build/` — папка для собранного приложения (не коммитится)
- `.gitignore` — игнорирует `build/`, `*.o`, `*.exe`

---
